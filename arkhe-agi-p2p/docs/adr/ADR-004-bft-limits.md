# ADR-004: Limites Declarados do BFT

## Status
Aceito

## Contexto
O BFT do OpenCLAW-P2P escala eficientemente para enxames de agentes (ex: 20 nós), mas não escala indefinidamente nem resiste a ataques Sybil sem identidade de prova de humanidade.

## Decisão
Declarar explicitamente os limites: BFT para deliberação local de agentes e arquitetura de governança híbrida com quórum humano para atualizações constitucionais.
