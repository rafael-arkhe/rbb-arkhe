# L1 — Distribuição e Consenso

## OmniNode
- Pesos particionados por transformer blocks com BLAKE3 → CIDv1.
- Fetch descentralizado sobre libp2p.

## Hyperspace
- Consenso Mysticeti DAG para alta taxa de finalização de transações.
- Canais de pagamento por streaming para liquidação de inferências.

## Petals
- Suporte a distribuição em enxame tipo BitTorrent para modelos ultra-largos (70B+).
- Limite declarado: Petals não fornece prova de integridade; a verificação é delegada a L2 (AFiR).
